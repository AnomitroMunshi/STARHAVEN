HOW TO USE
- Size: 1024 x 1536 pixels, vertical 2:3 (same as the existing portraits). In Grok pick the portrait / 2:3 aspect.
- Save each image as PNG into  starhaven_chars_image/  with the exact file name shown after "Save as" (.png).
  The wiki already points at these file names, so the portrait appears as soon as the file exists.
- Every prompt already includes the shared house style below. If Grok drifts, paste the style line again.

HOUSE STYLE (matches existing portraits such as kael.png, veyra.png, kethraBlackfang.png)
Photorealistic dark-fantasy character portrait, cinematic film still, desaturated moody color grade, overcast or low-key dramatic lighting, extremely detailed textures on skin, metal, leather and fabric, sharp focus on the character, softly blurred detailed background. Vertical 2:3 composition, 1024x1536, three-quarter to full-body view, character centered and filling most of the frame. No text, no watermark, no border, no logo.
